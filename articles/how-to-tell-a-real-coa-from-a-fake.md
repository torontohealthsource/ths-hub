### How can I tell if a certificate of analysis is real?

Start with where it is hosted. A report that opens on the testing laboratory's own domain under the lab's reference cannot be edited by the seller; a PDF served from the seller's site can. Then match the batch code, compound and strength, and the client name to what you bought.

### What is the single most important field to check?

The batch or lot code. The product name is shared by every run the seller has ever sold, so only the batch code connects a report to the specific vial in your hand.

### Is a professional-looking certificate a good sign?

No. Appearance is the easiest thing to fake and proves nothing. The two common problems are a genuine report reused long after its batch sold through, and a genuine report for a different batch — both look impeccable and both fail the batch match.
