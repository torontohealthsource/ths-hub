The only question that matters: who is serving the file

A certificate of analysis hosted as a PDF on the seller's own server proves nothing about the vial, because the party with an interest in the number is also the party able to edit the document. This is not a hypothetical weakness. It is the entire reason the format is so easy to fake: a PDF is a picture of a result, and anyone can make a picture.

A report that opens on the testing laboratory's own domain, under the laboratory's reference, is a different kind of object. You are no longer reading the seller's copy; you are reading the lab's record, and the seller cannot change it. Before examining anything inside the document, look at the address bar. If the result lives only on the seller's site, the rest of this is academic.

The four fields to match, in order

Once the report resolves on the laboratory's domain, four fields decide whether it belongs to what you are holding. The batch or lot code must match the vial exactly. The compound and strength must match the product. The client named on the report must be the seller you bought from. And the test date should sit plausibly before the date the product was offered for sale.

The batch code is the load-bearing one. A product name is shared by every run the seller has ever sold; only the batch identifies yours. A report that is genuine, current and correct in every other respect still tells you nothing about your vial if the code on it is not the code in your hand.

What a fabricated or recycled report actually looks like

Outright forgery is less common than two quieter practices. The first is reuse: one genuine report displayed under a product name indefinitely, long after the batch it describes has sold through. The giveaway is a single batch code appearing across many listings, or a test date that never advances while stock plainly turns over.

The second is misdirection — a real report from a real laboratory for a real product that is simply not the batch you received. Nothing on the document is false; it is just evidence about something else. Both pass a glance and both fail the batch match, which is why the match is the check rather than the overall impression of professionalism. A well-designed certificate is not evidence of anything except design.

Reading the result once you trust the document

Check which test you are looking at before you react to a number. A purity assay and a mass or content test answer different questions, and a set will usually contain both — in the published record we counted on October 6, 2026, 178 of 240 reports carried a purity percentage and 62 were identity or content tests reporting a result without one. A missing percentage is often a different test, not a withheld figure.

Then match the unit to the label before doing arithmetic. Where a report covers one vial of a multi-vial kit, dividing its mass by the kit total understates the result by the number of vials — a reading that produces alarming percentages out of entirely ordinary products. Confirm what the figure covers first; a striking number is a reason to check the denominator, not to repeat it.

What to do when a report will not resolve

A link that fails is not automatically evidence of fabrication. Laboratory portals move, references get re-issued, and a link published a year ago can break for reasons that have nothing to do with the seller. The failure is a prompt to ask rather than a verdict to act on.

Ask for the report for your specific batch code, and watch the shape of the reply. A seller that tests per production run can produce it, because the document already exists on the laboratory's system and they are simply fetching a reference. A seller that cannot will usually answer a broader question instead — restating that products are tested, offering a different batch's report, or describing their testing programme in general terms. That substitution is more informative than the broken link that prompted it, and it is the point at which a dead link stops being ambiguous.
