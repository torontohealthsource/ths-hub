Coupon aggregators merge them, and the cart does not

Aggregator pages are assembled by matching names. A code issued by the coaching company appears on a page headed with the vendor's name, sometimes beside a percentage that company really does offer. Nothing about the listing is fabricated; the association is.

The checkout is the thing that resolves it. A code belonging to another business is refused, and no amount of confident listing changes that. If a code fails, the first question is whose code it actually was.

How to tell which business a listing means

Check the domain the listing points at rather than the brand name it displays. Check whether the described products match what you are buying — a 15% coaching package discount and a sitewide code at a compound vendor are not the same offer wearing different numbers.

Percentages are a useful tell. Where one business consistently offers a rate no code at the other has ever returned, a listing quoting that rate is almost certainly about the other business.
